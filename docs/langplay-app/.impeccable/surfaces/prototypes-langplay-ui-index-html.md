# LangPlay playback addition

Mode: Operate, inside the host player. Scope: isolated code-first UI direction study; preserve Seanime library/tracking. The user confirmed on-demand tools. Accent remains a proposed default.

## Direction contract

THESIS: The scene remains uninterrupted while watching; selecting a Japanese word pauses it and opens contextual learning.

OWN-WORLD: Inherit Seanime's near-black player, practical sans-serif UI, restrained corners and edge controls. Opaque charcoal drawer, white Japanese text with local contrast backing, provisional amber selection.

STORY: Watch, select, read a concise dictionary result, optionally explain/save, explicitly resume. Close or Escape never resumes. All study content and services are labelled simulated.

FIRST VIEWPORT: Large original platform still under the title and above the timeline. Japanese subtitle centered in the lower safe area. Small edge actions open a single right drawer, 360–380 px on desktop, for lookup/subtitles/transcript/settings. Narrow layouts retain a visible scene above a bottom sheet.

FORM: Local extension of an established host surface; concept-seed is intentionally not run for local additions, per new-work section 3. No replacement visual identity or concept tournament.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
